# AmenityBento

The house amenities as a bento grid with exactly one cell per amenity.

- **Provide:** five amenities, each with a title, one sentence and a Phosphor icon; the lead amenity (breakfast) also gets a photo.
- Cells vary on purpose: one wide photo cell, one tall `coral-soft` cell, one `jungle-soft` cell and two plain `ground-raised` cells.
- If the number of amenities changes, reshape the grid so no cell is empty. Long lists (more than five) go on the room page grouped under headings.
