# SiteFooter

The closing band on every page: mark, page links, contact details and house basics.

- **Provide:** phone, email, WhatsApp number, check-in and check-out times, and links to house rules and cancellation policy.
- Sits on `ground-sunk` in the page's own theme (no inverted dark footer).
- Contact details are buttons that copy the value, so they work where tel: and mailto: links don't.
- Contact values in the previews are placeholders.
