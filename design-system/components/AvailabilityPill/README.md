# AvailabilityPill

A small status label for a room or date range.

- **Provide:** the state class (`sv-pill--available`, `--few`, `--booked`) and the words. The word carries the meaning; the dot only supports it.
- `available` uses `jungle`, `few` uses `coral-ink`, `booked` uses `error`. All pass 4.5:1 on every ground.
- This is the only place a coloured dot appears, because it shows real state.
