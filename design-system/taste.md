# Taste rules

The site follows the taste-skill guidance (github.com/Leonxlnx/taste-skill). These are the rules that shape Sam Villa, applied to this brand.

## Design read

Hospitality landing page for travellers choosing a small B&B, with a warm and inviting language, built in native CSS on these tokens. Dials: DESIGN_VARIANCE 6 (offset, asymmetric splits), MOTION_INTENSITY 4 (fluid CSS, no scroll hijacking), VISUAL_DENSITY 3 (airy).

## What it changed

| Rule | How Sam Villa follows it |
| --- | --- |
| Serif only when justified | Headings moved from a serif to Bricolage Grotesque, a sans display face. |
| No beige, brass and espresso palette | A bright sea-salt white ground, a fresh garden green and one soft coral accent ("Forest" family plus a single saturated pop). |
| One accent, locked | Coral appears only on the booking CTA, stars and the nav marker. |
| One shape system | Pills for anything pressable, `radius-lg` for anything viewable, the arch for lead photos. |
| No centred hero | Asymmetric split: copy left, arched photo right. |
| Hero stack of 4 elements max | Eyebrow, headline, 15-word subtext, CTA row. |
| No three equal cards | Rooms are one featured card plus a compact stack. |
| Bento with exact cell count | Five amenities, five cells, varied backgrounds. |
| Every section a different layout | Split hero, booking bar, offset photo collage, featured rooms, bento, photo band, score with quote, map split, centred closing band. |
| Eyebrows rationed | Two eyebrows across nine sections. |
| No middle-dot strings or decorative dots | Room facts are icon and label pairs; the only dot is the real availability state. |
| One CTA label per intent | "Check availability" everywhere for booking. |
| Labels above inputs, errors below | All booking fields. |
| Library icons only | Phosphor, one weight. |
| Real images or labelled slots | Labelled photo slots name each shot needed. |
| No em-dashes | None anywhere in copy. |
| Sample numbers are marked | Rates, score, reviews and travel times are labelled as samples. |
| Theme lock, reduced motion | One light theme for the whole site (the owner asked for light colors); all motion off under reduced motion. |

## Pre-flight before shipping a page

- Hero fits the first screen: headline 2 lines max, subtext 20 words max, CTA visible.
- Nav on one line at desktop, header 80px max.
- Every CTA label fits on one line and passes 4.5:1.
- No section layout used twice, no more than two image and text splits in a row.
- Every visible string re-read for plain, correct English.
